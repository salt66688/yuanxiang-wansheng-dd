# 杭州元像万生科技有限公司 投资尽调报告

> 投资人视角尽职调查（非审计、非法律意见）  
> 调查对象：杭州元像万生科技有限公司（曾用名：杭州乐书数字科技有限公司、杭州昱财科技有限公司；统一社会信用代码 `91330109MABU52HJ0G`）

---

## 结论

**不建议以任何估值参与本轮投资。**

理由不是"增长不及预期"，而是**披露基础不成立**：投资人据以定价的核心指标（累计放款、客户数、GMV、息费收入、AI 能力）均无法通过独立核验，其中放款规模与收入已被证实存在系统性虚增。在披露基础被污染、且创始人历史纠纷尚未了结的情况下，任何估值模型都失去意义。

## 六条核心发现

1. **约六成放款为标记类订单**——无真实资金流、无真实回款，单笔金额断层（40 万+ vs 5 万）、逾期率反向（<0.5% vs 4%+）、月末年末逐日连发。
2. **收入在数学上不成立**——10 亿元放款只对应 660 万元息费，因为标记类订单走独立记账口径与计息参数，与真实业务隔离。
3. **规模呈时点冲量特征**——2024 年末、2025 年末两个时点集中爆发，单笔 800–990 万元、同一企业连续 6–7 天每日一笔、全部"正常结清"、零逾期。
4. **沿革是"换壳 + 换故事"**——上一段创业与外部投资人发生纠纷后团队整体平移，三年内三次更名、两次业务口径重构；现主体对外长期借用前主体的"成立于 2021 年 12 月"。
5. **"AI 基座大模型"业务无产品、无客户、无收入**——供应站/需求站入口全部 404，无数据目录、定价、样例与成交记录，技术底座是 2023 年的旧电商后台。
6. **存续依赖投资人款项**——连续约八个月无法正常发放工资，人员与核心技术资产大幅流失，2026 年二至三季度连续约五个月零放款。

## 风险清单

**红色（致命）**
- **R1** 经营数据系统性造假：约六成放款为标记类订单
- **R2** 收入失真：息费按内部口径隔离记账
- **R3** 新业务无实质：AI / 数据要素业务无产品、无客户、无收入
- **R4** 对外宣传与既成事实背离：已终止两年的合营仍在官网宣传

**橙色（重大）**
- **O1** 主体资本与业务规模严重不匹配（125 万实缴主体承载十亿元级叙事）
- **O2** 治理结构失衡（业务负责人无股权、无高管身份）
- **O3** 创始人历史纠纷未了结
- **O4** 用工主体分散，持股平台零参保
- **O5** 境外架构空心化（香港主体股本均 1 万港币，押记登记册为空）
- **O6** 业务连续数月停摆

**黄色（需持续监控）**
- **Y1** 渠道结构含自然人中介（两家合计逾 1,000 笔）
- **Y2** 借款企业高度集中，含苗木、农产品、传媒等非电商业态
- **Y3** 数据合规瑕疵（注册即收身份证号，与隐私政策冲突）
- **Y4** 现有域名与系统维护停滞（商城域名解析失败、TLS 证书过期未续）
- **Y5** 增值电信许可 2026-09-03 方取得，资质历史短
